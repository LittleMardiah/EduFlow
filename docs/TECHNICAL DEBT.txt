HASIL PERCOBAAN :

1. TD-EDU-CODE-003 - Ownership Middleware (Refactor)
Status: SELESAI (2026-08-02)

Apa yang dilakukan:
1. Debug root cause: Ownership middleware sebelumnya mengakses Prisma langsung,
   melanggar separation of concerns dan sulit di-test.

2. Refactor ownership.middleware.ts:
   - Gunakan repository functions (`getQuizById`, `findQuestionById`) 
     daripada akses Prisma langsung.
   - Tambahkan support untuk resource 'option' (sebelumnya hanya 'quiz' & 'question').
   - Admin bypass (role === 'admin' → langsung next()).
   - Error handling lengkap: 401 (no token), 403 (not owner), 404 (not found).

3. Integrasikan ke semua routes:
   - quiz.routes.ts: 5 endpoint pakai requireOwnership('quiz').
   - question.routes.ts: 3 endpoint pakai requireOwnership('question').
   - option.routes.ts: 2 endpoint pakai requireOwnership('option').

4. Validasi dengan integration test:
   - Instructor B PATCH quiz A → 403 (ownership enforced).
   - Admin PATCH quiz A → 200 (admin bypass).
   - Instructor A DELETE own quiz → 204 (owner can delete).

Hasil Verifikasi:
- Ownership middleware hanya akses repository, bukan Prisma langsung.
- Support 3 resource types (quiz, question, option).
